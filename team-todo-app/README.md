# ระบบติดตามงานทีมงาน (TeamTask Hub & Kanban Overview)
## ☁️ รองรับเชื่อมต่อ Google Sheets และแชร์ใช้งานร่วมกันในทีม

เว็บแอปพลิเคชันจัดการและติดตามงานทีมงาน (Todo & Kanban 5 คอลัมน์) สามารถแชร์ให้ทุกคนในทีมใช้งานพร้อมกันผ่าน **Google Sheets + Google Apps Script Web App** ได้จากทั้งคอมพิวเตอร์และมือถือ

---

## 🌟 จุดเด่นเมื่อเชื่อมต่อกับ Google Sheets

1. **ใช้งานร่วมกันได้ทั้งทีมแบบเรียลไทม์**:
   - ข้อมูลงานถูกจัดเก็บไว้ที่ Google Sheets กลางบน Google Drive
   - เมื่อหัวหน้าสั่งงาน หรือลูกทีมอัปเดตสถานะ ข้อมูลจะซิงค์หากันอัตโนมัติ
2. **เปิดใช้งานผ่านมือถือได้ทันที (Web App Link)**:
   - นำลิงก์ Web App ที่ได้จาก Google Apps Script ส่งเข้ากลุ่ม LINE หรืออีเมล ทีมงานสามารถเปิดดูบอร์ดของตนเองและเลื่อนสถานะงานได้ทันที ไม่ต้องติดตั้งแอปเพิ่ม
3. **เปิดดูและแก้ไขจาก Google Sheets ได้โดยตรง**:
   - มีชีต `Tasks`, `Members`, `Settings` บันทึกรายละเอียดงานครบถ้วน
4. **โหมดผสมผสาน (Hybrid Mode)**:
   - หากเปิดผ่านไฟล์ในเครื่อง (`index.html`) ก็สามารถเชื่อมต่อกับ Google Sheets กลางได้เช่นกัน

## 🚀 วิธีติดตั้งเชื่อมต่อ Google Sheets (ใช้เวลา 2-3 นาที)

### ขั้นตอนที่ 1: สร้าง Google Sheets ใหม่
1. ไปที่ [Google Drive](https://drive.google.com) ของคุณ
2. กดปุ่ม **+ ใหม่ (+ New)** ➔ เลือก **Google ชีต (Google Sheets)**
3. ตั้งชื่อไฟล์ตามต้องการ เช่น `TeamTask_Database`

### ขั้นตอนที่ 2: ติดตั้งโค้ดสคริปต์
1. ในหน้า Google Sheets ไปที่เมนู **ส่วนขยาย (Extensions)** ➔ **Apps Script**
2. **ใส่ไฟล์โค้ดที่ 1 (Code.gs)**:
   - ดับเบิลคลิกไฟล์ [**`1_คัดลอก_GoogleSheetsAPI_gs.bat`**](file:///c:/Users/ASCO-Y25-07012/Downloads/Test%20steel/team-todo-app/1_คัดลอก_GoogleSheetsAPI_gs.bat) เพื่อคัดลอกโค้ดลง Clipboard
   - สลับไปที่หน้า Apps Script เลือกไฟล์ `Code.gs` กด `Ctrl + A` แล้วกด `Ctrl + V` (วางทับ) จากนั้นกดบันทึก (`Ctrl + S`)
3. **ใส่ไฟล์โค้ดที่ 2 (Index.html)**:
   - ในหน้า Apps Script ให้กดปุ่ม **[+]** ข้างคำว่า "ไฟล์" (Files) ➔ เลือก **HTML**
   - ตั้งชื่อไฟล์ว่า: **`Index`**
   - ดับเบิลคลิกไฟล์ [**`2_คัดลอก_Index_html.bat`**](file:///c:/Users/ASCO-Y25-07012/Downloads/Test%20steel/team-todo-app/2_คัดลอก_Index_html.bat) เพื่อคัดลอกโค้ดลง Clipboard
   - กลับมาที่หน้าไฟล์ `Index.html` ใน Apps Script กด `Ctrl + A` แล้วกด `Ctrl + V` (วางทับ) จากนั้นกดบันทึก (`Ctrl + S`)

### ขั้นตอนที่ 3: สั่งสร้างตารางฐานข้อมูลอัตโนมัติ
1. ที่แถบเครื่องมือด้านบนของ Apps Script มองหาช่องเลือกฟังก์ชัน (ข้างปุ่มเรียกใช้)
2. เลือกฟังก์ชันชื่อ **`setupDatabase`**
3. กดปุ่ม **"เรียกใช้" (Run)**
4. ระบบจะขอสิทธิ์เข้าถึง Google Sheets:
   - กด **"ตรวจสอบสิทธิ์" (Review Permissions)**
   - เลือกบัญชี Google ของคุณ
   - กด **"ขั้นสูง" (Advanced)** ➔ กด **"ไปที่ ... (ไม่ปลอดภัย)" / Go to project**
   - กด **"อนุญาต" (Allow)**
5. เมื่อรันเสร็จ สลับกลับไปดูที่ Google Sheets จะพบตาราง `Tasks` และ `Members` ถูกสร้างขึ้นพร้อมข้อมูลตัวอย่างเริ่มต้นเรียบร้อยแล้ว

### ขั้นตอนที่ 4: เผยแพร่เป็นเว็บแอป (Deploy Web App)
1. กดปุ่มสีน้ำเงินมุมขวาบน **"การทำให้ใช้งานได้" (Deploy)** ➔ เลือก **"รายการใหม่" (New deployment)**
2. คลิกรูปฟันเฟือง ⚙️ (เลือกประเภท) ➔ เลือก **"เว็บแอป" (Web app)**
3. ตั้งค่า 3 จุดดังนี้:
   - **คำอธิบาย (Description)**: `TeamTask v1`
   - **ดำเนินการในฐานะ (Execute as)**: `ฉัน (Me)`
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access)**: **`ทุกคน (Anyone)`** *(สำคัญมาก เพื่อให้ทีมงานเปิดได้โดยไม่ต้องขอสิทธิ์)*
4. กดปุ่ม **"ทำให้ใช้งานได้" (Deploy)**
5. **คัดลอก "URL เว็บแอป" (Web App URL)** ที่ได้:
   - **วิธีที่ 1**: ส่งลิงก์นี้เข้า LINE ให้ทีมงานเปิดใช้งานผ่านมือถือ/คอมพิวเตอร์ได้ทันที!
   - **วิธีที่ 2**: นำลิงก์นี้ไปวางในหน้าเว็บแอป (กดปุ่ม `☁️ Google Sheets` ที่มุมขวาบน แล้วกดวาง URL) เพื่อให้เว็บในเครื่องซิงค์ข้อมูลกับ Google Sheets กลาง
